# Фирменные ресурсы Neutrivox

Здесь размещаются логотип, иконки приложения и другие графические ресурсы.

Для Neutrivox утверждён фирменный логотип, предоставленный владельцем проекта в процессе разработки. При следующем этапе сборки исходный PNG будет добавлен в репозиторий в технических вариантах для приложения и установщика (включая Windows ICO) без изменения фирменного дизайна.
