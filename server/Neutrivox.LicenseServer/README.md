# Neutrivox License Server

Небольшой сервер аккаунтов и лицензий для сценария «одна покупка — один аккаунт — несколько разрешённых ПК».

## Что делает

- однократно связывает подписанный ключ покупки с аккаунтом;
- хранит пароль только как PBKDF2-SHA256 hash + random salt;
- хранит только SHA-256 от session token;
- ограничивает частоту register/login запросов;
- ограничивает число активных ПК: Standard 2, Professional 3, Business 5, Owner 10;
- позволяет отключить старый ПК из аккаунта;
- не принимает истёкшую подписку;
- не принимает один и тот же purchase key для второго аккаунта.

## Важно

Сервер нужно публиковать только за HTTPS reverse proxy. Desktop-клиент Neutrivox намеренно отказывается отправлять пароль на `http://` URL.

Текущий JSON datastore рассчитан на один экземпляр небольшого лицензионного сервера. Перед горизонтальным масштабированием его следует заменить на транзакционную БД (PostgreSQL/SQL Server) с миграциями и резервным копированием.

## Docker

Из корня репозитория:

```bash
docker build -f server/Neutrivox.LicenseServer/Dockerfile -t neutrivox-license-server .
docker run -d --name neutrivox-license \
  -p 127.0.0.1:8080:8080 \
  -v /opt/neutrivox/license-data:/data \
  --restart unless-stopped \
  neutrivox-license-server
```

Проверка внутри сервера:

```bash
curl http://127.0.0.1:8080/health
```

Затем проксируйте публичный адрес вроде `https://license.example.com` на `127.0.0.1:8080` через Caddy/Nginx и укажите HTTPS URL в **Neutrivox → Настройки → Аккаунт**.

## GGSEL-сценарий

1. Покупатель устанавливает Neutrivox и копирует fingerprint из Настроек.
2. Владелец выпускает подписанный ключ через `tools/Neutrivox.LicenseIssuer` с этим fingerprint.
3. Покупатель получает ключ через GGSEL.
4. При создании аккаунта ключ расходуется один раз и закрепляет entitlement за аккаунтом.
5. На следующем своём ПК покупатель устанавливает Neutrivox и входит тем же аккаунтом. Сервер добавляет ПК, пока не достигнут лимит тарифа.
6. Старый ПК можно отключить из списка устройств.

Пароль аккаунта продавцу не нужен и передаваться не должен.
