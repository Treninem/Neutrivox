# Neutrivox

Neutrivox — современная среда для создания и настройки проектов промышленной автоматизации.

## Что уже создано

Первый рабочий фундамент desktop-приложения:

- современное главное окно;
- русский и английский интерфейс с переключением языка;
- создание первого проекта;
- навигация по разделам проекта;
- модели проектов, устройств, соединений и каналов ввода/вывода;
- локальное сохранение и открытие проектов в JSON;
- расширяемый каталог оборудования;
- базовая проверка конфигурации;
- автоматическая проверка сборки в GitHub Actions.

## Цель проекта

Сделать понятную программу на русском и английском языках для работы с контроллерами, модулями расширения, входами/выходами и схемами подключения.

## Основные принципы

- понятный интерфейс для новичков и профессионалов;
- русский и английский языки;
- модульная архитектура для добавления нового оборудования;
- визуальное проектирование;
- безопасная работа только с оборудованием и системами, которыми пользователь имеет право управлять;
- прозрачное лицензирование без обхода защит и чужих лицензий.

## Запуск разработки

Требуется .NET SDK 8 или новее:

```bash
dotnet restore Neutrivox.sln
dotnet run --project src/Neutrivox/Neutrivox.csproj
```

## План разработки

1. Развить проекты и полноценное сохранение данных.
2. Добавить каталог оборудования и карточки устройств.
3. Реализовать настройку входов и выходов.
4. Создать визуальный редактор схем.
5. Добавить диагностику и проверки проекта.
6. Реализовать поддерживаемые способы подключения оборудования.
7. Добавить полноценную локализацию и систему лицензирования.

Подробная архитектура и ход разработки документируются в репозитории.
