# Neutrivox

Neutrivox — desktop-среда для проектирования и настройки проектов промышленной автоматизации.

## Основная идея

Один проект объединяет оборудование, I/O, схему, логику, симуляцию, диагностику и последующую работу с физическими устройствами. Подключение прибора не создаёт отдельный режим «с прибором» — физическое устройство становится подтверждённым состоянием уже существующего объекта проекта.

## Что уже есть в репозитории

- настоящее desktop-приложение на Avalonia/.NET;
- RU/EN интерфейс и документация;
- модель проекта, оборудования, I/O, связей, тегов и логики;
- автономная симуляция без физического оборудования;
- сохранение/загрузка и recovery;
- каталоги и профили оборудования;
- discovery и binding физических endpoint;
- RS-485/Modbus RTU транспортный фундамент;
- preflight, safety gate и последовательный deployment workflow;
- детерминированный внутренний deployment payload с SHA-256;
- централизованная система коммерческих планов и feature access;
- Free и платные планы с ценами в рублях;
- отдельная персональная Owner Lifetime-лицензия, не выставляемая на публичную продажу;
- непрерывные журналы требований и разработки;
- release-gate checklist;
- воспроизводимая Windows publish-команда и заготовка установщика.

## Важное ограничение физической загрузки

Neutrivox не объявляет устройство готовым к записи только потому, что его удалось обнаружить. Для физической передачи требуется одновременно:

`подтверждённая модель` → `совместимость проекта` → `конкретный verified deployment adapter` → `preflight` → `явное подтверждение пользователя`.

Это особенно важно для ОВЕН ПР100: официальная документация указывает Owen Logic и microUSB/USB для программирования, а RS-485 — для Modbus RTU/Modbus ASCII в соответствующих модификациях. Поэтому Modbus не используется как выдуманный способ загрузки самой программы.

## Оборудование

Профили ОВЕН и реальные транспортные возможности добавляются на основе документации производителя. Неподтверждённый внутренний протокол не маркируется как production-ready.

## Коммерческая модель

Free — минимальный базовый функционал без оплаты.

Standard — расширенная работа по подписке.

Professional — профессиональные функции, включая последовательную физическую передачу там, где есть проверенный production adapter.

Owner Lifetime Max — персональный бессрочный уровень владельца; не публикуется как товар.

Продажа ключей допускается через внешнюю торговую площадку, включая GGSEL. Ядро программы не зависит от самой площадки.

## Разработка и проверка

Restore/build:

```bash
dotnet restore Neutrivox.sln
dotnet build Neutrivox.sln --configuration Release
```

Smoke test:

```bash
dotnet build tools/Neutrivox.Smoke/Neutrivox.Smoke.csproj --configuration Release
dotnet run --project tools/Neutrivox.Smoke/Neutrivox.Smoke.csproj --configuration Release --no-build
```

Windows publish:

```powershell
.\scripts\Build-Windows.ps1
```

После publish установщик собирается из `installer/Neutrivox.iss` с помощью Inno Setup.

## Статус

Проект находится на стадии активной интеграции и подготовки к релиз-кандидату. Никакая физическая функция не считается завершённой без фактической проверки соответствующего оборудования/протокола.
