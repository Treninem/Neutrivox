# Neutrivox 0.2.0

Neutrivox — настольная среда проектирования промышленной автоматизации для Windows. Один проект объединяет оборудование, входы/выходы, связи, логику, симуляцию, диагностику и безопасное сопоставление с физическими приборами.

## Установка

1. Запустите `Neutrivox-Setup-0.2.0.exe`.
2. Следуйте мастеру установки.
3. Запустите Neutrivox через ярлык.

Для portable-варианта распакуйте `Neutrivox-win-x64-0.2.0.zip` и запустите `Neutrivox.exe`.

## Первый запуск

При первом запуске автоматически начинается 7-дневный Professional trial. После его окончания программа переходит в Free: базовое проектирование и симуляция остаются доступны. Платный ключ можно активировать в **Настройки → Лицензия**.

## Основной рабочий процесс

1. Нажмите **Новый проект** или **Открыть**.
2. В разделе **Оборудование** добавьте контроллеры, реле, модули связи и I/O.
3. В **Входы и выходы** подпишите каналы.
4. В **Схема** настройте состав и связи проекта.
5. В **Логика** создайте сети, переменные и инструкции.
6. В **Симуляция** запустите проект без физического оборудования и проверьте входы/выходы и трассировку.
7. В **Проверка** исправьте блокирующие ошибки.
8. Сохраните проект в файл `.neutrivox`.

Neutrivox делает автоматический recovery-снимок примерно каждые 30 секунд. Последний снимок можно восстановить из раздела **Проекты**.

## Физические приборы

Раздел **Подключение** поддерживает:

- поиск COM-портов и безопасный Modbus RTU discovery;
- поиск доступных TCP/502 endpoint в явно заданном IPv4-адресе или CIDR-диапазоне;
- отмену поиска;
- отдельную проверку совместимости;
- явное подтверждение сопоставления найденного прибора с объектом проекта.

Наличие открытого IP/COM-порта не считается доказательством модели прибора. Если документированный профиль не определён, Neutrivox не разрешает подтверждать модель автоматически.

## Передача конфигурации в прибор

Физическая запись намеренно имеет строгий safety gate. До записи должны одновременно выполняться условия:

- выбран конкретный объект проекта;
- физический прибор сопоставлен и идентифицирован;
- найден точный документированный профиль;
- профиль имеет статус аппаратно проверенной read/write-поддержки;
- зарегистрирован протестированный deployment adapter;
- preflight не содержит блокирующих ошибок;
- план не изменился после проверки;
- пользователь вручную вводит `DEPLOY` перед запуском.

Для поддерживаемых программируемых реле ОВЕН предусмотрена интеграционная точка с официальной **Owen Logic Replication Utility**. Путь к официальной утилите задаётся в **Настройки**. Neutrivox не выдумывает закрытый протокол программирования и не помечает непроверенные модели как готовые к физической записи.

## Поддерживаемые семейства оборудования

Каталог содержит точные профили ПР100 и семейства оборудования ОВЕН (ПР, ПЛК, СПК, Мх, ПРМ, ПМ/ПЕ/ПВ210), Siemens, Schneider Electric, Mitsubishi Electric, OMRON, Delta, WAGO, Allen-Bradley, Beckhoff и Weintek. Для семейного профиля точное количество I/O не придумывается — оно появляется только после добавления проверенного профиля конкретной модификации.

## Лицензирование

Публичные тарифы и цены хранятся в рублях. Лицензии подписываются RSA. Приложение содержит только публичный ключ; закрытый ключ владельца не должен находиться в репозитории, установщике или на компьютерах клиентов.

Для выпуска ключей владельцем используется `tools/Neutrivox.LicenseIssuer`. Ключ может быть привязан к отпечатку конкретного компьютера.

## Где хранятся локальные данные

В `%LOCALAPPDATA%\Neutrivox` хранятся пользовательские настройки, состояние trial/лицензии и recovery-снимок. Проекты сохраняются туда, куда пользователь выбрал файл `.neutrivox`.

## Важное ограничение релиза

Цифровое проектирование, сохранение, логика, симуляция, диагностика, лицензирование и упаковка проверяются автоматически в CI. Физическую запись в конкретную модель нельзя считать подтверждённой только программными тестами: каждая модель/адаптер должна отдельно пройти испытание на реальном оборудовании. Пока это не сделано, safety gate оставляет запись заблокированной.
