# Редактор логики Neutrivox

## Назначение

Редактор логики является частью единого проекта. Логика создаётся один раз и может проверяться в симуляторе до связи проекта с реальным оборудованием.

## Основные элементы

### Сеть
Сеть — упорядоченная последовательность логических инструкций. Сети можно включать и отключать.

### Инструкция
Каждая инструкция имеет тип операции, целевой символ и один или несколько исходных символов. Редактор использует каталог доступных операций вместо произвольного выполнения текста.

### Символы
В качестве значений используются каналы оборудования, теги и логические переменные проекта. Это позволяет диагностировать неизвестные ссылки до моделирования.

## Рабочий порядок

1. Создайте сеть.
2. Добавьте инструкции из набора операций.
3. Выберите входы и целевые значения.
4. Проверьте логику.
5. Запустите моделирование.

## Безопасность

Редактирование логики само по себе не изменяет физическое оборудование. Перед реальной передачей конфигурация должна пройти отдельные проверки и быть явно назначена конкретному прибору.
