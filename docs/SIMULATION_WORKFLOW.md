# Симуляция и диагностика Neutrivox

## Единый рабочий цикл

Симуляция использует тот же проект, который пользователь создаёт для будущей работы с оборудованием. Перед циклом программа проверяет проект, затем выполняет доступную логику и сохраняет понятную трассировку событий.

## Что происходит при запуске

1. Создаётся или продолжается сессия симуляции.
2. Выполняется проверка проекта и логики.
3. При критических ошибках выполнение останавливается до изменения виртуальных значений.
4. При успешной проверке выполняются включённые логические сети.
5. Ошибки и результат сохраняются в трассировке.
6. Пользователь может сохранить состояние симуляции в снимок и вернуться к нему.

## Почему симуляция отделена от физического оборудования

Симулятор не открывает сетевые соединения и не отправляет команды приборам. Это позволяет безопасно проверять идею проекта до выбора конкретного физического устройства и отдельной операции передачи.

## Снимки состояния

Снимок хранит текущие значения виртуальных каналов и тегов. Он предназначен для экспериментов и не заменяет сохранение самого проекта.

## Следующее развитие

Интерфейс будет отображать запуск, ошибки, трассировку и восстановление состояния без создания отдельного проекта для симуляции.
