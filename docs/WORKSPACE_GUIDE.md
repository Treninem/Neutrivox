# Рабочее пространство Neutrivox

Рабочее пространство показывает единый проект целиком. Здесь отображаются устройства проекта, их связи и выбранный объект.

## Основной принцип

Схема является представлением существующего проекта, а не отдельной копией данных. Один проект используется и для моделирования, и для дальнейшей работы с физическим оборудованием.

## Работа с устройствами

Устройства автоматически получают начальное расположение. В дальнейшем пользователь сможет изменять расположение, видеть связи и открывать свойства выбранного объекта.

## Соединения

Соединение связывает существующие объекты проекта. Перед созданием связи программа должна проверять корректность выбранных объектов.

## Развитие

Следующие изменения добавят интерактивное размещение, визуальные линии соединений, свойства объектов и масштабирование рабочего поля.
