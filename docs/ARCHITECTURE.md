# Архитектура Neutrivox

## Принцип

Ядро программы не зависит от конкретной модели оборудования. Поддержка устройств добавляется через описания и драйверы, чтобы новые контроллеры и модули можно было подключать без переписывания всей программы.

## Основные слои

### Application
Пользовательский интерфейс, проекты, команды и навигация.

### Domain
Модели проекта, устройств, каналов ввода/вывода, соединений и проверки конфигурации.

### Device Catalog
Каталог поддерживаемого оборудования и его характеристик.

### Communication
Подключение к оборудованию через поддерживаемые протоколы и интерфейсы. Любая операция записи должна требовать явного действия пользователя и проверок совместимости.

### Licensing
Отдельный сервис проверки лицензии. Лицензионный ключ не должен содержать секреты или давать доступ к чужим системам.

## Данные проекта

Проект должен содержать:

- название и метаданные;
- список устройств;
- конфигурацию входов и выходов;
- соединения;
- параметры сети;
- историю проверок.

## Безопасность

Neutrivox не предназначен для обхода защиты, несанкционированного доступа или вмешательства в системы без разрешения владельца. Перед передачей конфигурации на физическое оборудование программа должна показывать понятное подтверждение и результаты проверки.
