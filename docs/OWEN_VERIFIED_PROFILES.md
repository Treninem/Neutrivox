# Проверенные профили ОВЕН в Neutrivox

Профили ниже основаны на официальной документации ОВЕН, проверенной при разработке 28.08.2026.

## ПР100

Официальная страница ПР100 содержит отдельные руководства для следующих модификаций:

- ПР100-230.0804.01.0
- ПР100-230.0804.01.1
- ПР100-230.1208.01.0
- ПР100-230.1208.01.1
- ПР100-24.0804.03.0
- ПР100-24.0804.03.1
- ПР100-24.1208.03.0
- ПР100-24.1208.03.1

В проекте эти модификации не объединяются в один безымянный набор I/O. Каждая имеет отдельный профиль, чтобы пользователь видел конкретное исполнение.

Для модификаций `.01.1` и `.03.1` профиль отражает наличие RS-485. Для соответствующих вариантов без `.1` профиль отражает отсутствие RS-485.

Официальная документация ОВЕН указывает для ПР100 интерфейс RS-485 и протоколы Modbus RTU/Modbus ASCII для исполнений с соответствующим интерфейсом. При этом наличие Modbus не считается доказательством возможности передачи пользовательской программы Owen Logic.

## ПМ210

Официальная документация ОВЕН описывает ПМ210 как сетевой шлюз для подключения приборов по RS-485/Modbus к OwenCloud. Варианты включают исполнение с GSM/LTE; ПМ210 не следует моделировать как контроллер с пользовательской программой ПР100.

Поэтому профиль ПМ210 в Neutrivox относится к коммуникационному устройству, а не к цели загрузки программы контроллера.

## Почему это важно для Neutrivox

`Manufacturer + Model + Variant` должны вести к точному профилю. IP-адрес или наличие открытого порта не могут самостоятельно объявлять устройство конкретной моделью.
