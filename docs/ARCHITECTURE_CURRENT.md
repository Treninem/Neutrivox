# Текущая архитектура Neutrivox

## Главный принцип

В основе Neutrivox находится один `AutomationProject`. Оборудование, каналы, связи, схема, логика и данные симуляции относятся к одному рабочему проекту. Подключение реального прибора не создаёт второй тип проекта.

## Основные слои

### Модель проекта
Хранит оборудование, I/O, соединения, теги и логическую программу.

### Рабочие сервисы
Отдельные сервисы отвечают за каталог устройств, добавление оборудования, связи, рабочее пространство, логику и проверки. Они не должны содержать дублирующие состояния интерфейса.

### Единая сессия
`ProjectSessionService` объединяет текущий открытый проект, виртуальное состояние симуляции и историю изменений текущей рабочей сессии. Это основа для сохранения, восстановления и будущего undo/redo.

### Логика
`LogicEditorWorkflowService` управляет изменениями, а `LogicEditorPresenterService` собирает данные для интерфейса: сети, переменные, символы, инструменты и результаты проверки.

### Симуляция
Работает с тем же проектом и не связывается с физическим оборудованием. Сценарии позволяют повторять проверки с заданными виртуальными входами, снимки позволяют восстановить состояние эксперимента.

### Физическое оборудование
Подключение и передача конфигурации являются отдельными явно подтверждаемыми операциями. Они не должны автоматически выполняться при симуляции или редактировании проекта.

## Почему архитектура развивается так

Сначала создаётся надёжный общий проектный фундамент и проверяемая цифровая среда. Затем к ней подключаются реальные профили и транспортные адаптеры. Такой порядок позволяет тестировать большую часть поведения без риска отправки неподтверждённых данных в физическое оборудование.

## Следующие архитектурные задачи

1. Подключить новые сервисы к полноценному интерфейсу логики и симуляции.
2. Добавить постоянное сохранение проекта и безопасное восстановление.
3. Ввести подтверждённые профили конкретных поддерживаемых устройств.
4. Реализовать обнаружение и связь через отдельные адаптеры.
5. Добавить тесты и выпускной конвейер.
