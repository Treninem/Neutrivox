# Архитектура реальных адаптеров

## Зачем нужен отдельный адаптер

Модель проекта не должна знать детали TCP, RS-485, USB или конкретного протокола. Эти детали принадлежат адаптеру конкретного семейства устройств.

## Probe и Transfer разделены

`ProbeAsync` предназначен только для получения сведений об устройстве. `TransferAsync` предназначен для отдельной операции передачи. Наличие возможности обнаружить устройство не означает наличие права или технической возможности записывать конфигурацию.

## Защита передачи

Перед передачей должен существовать:

1. конкретный объект проекта;
2. конкретное физическое устройство;
3. подтверждённая идентификация;
4. проверка совместимости профиля;
5. готовый payload правильного формата;
6. явное подтверждение оператора.

`PhysicalAdapterGate` не разрешает передачу при отсутствии подтверждённой идентификации.

## Принцип для ОВЕН

Для ПР100 наличие Modbus RS-485 само по себе не превращает Modbus-адаптер в загрузчик Owen Logic. Отдельный адаптер передачи программы будет создан только после проверки официально документированного способа передачи и фактического тестирования.

## Следующий блок

Добавить конкретный адаптер чтения/обнаружения для первого подтверждённого интерфейса, затем интегрировать его в экран поиска устройств. Операция записи в реальный прибор остаётся закрытой, пока протокол и формат не подтверждены.
