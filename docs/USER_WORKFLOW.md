# Как устроена работа в Neutrivox

## Один проект

В Neutrivox нет отдельных режимов «работа без прибора» и «работа с прибором». Пользователь всегда работает с одним проектом.

## Создание

Добавьте оборудование и настройте его цифровые модели. Реальный прибор для этого не нужен.

## Логика и моделирование

Настройте каналы, переменные и программу. Затем запустите симуляцию и меняйте виртуальные входы, наблюдая за состоянием проекта.

## Реальное оборудование

Когда оборудование подключено, программа может использовать поддерживаемые механизмы обнаружения для поиска доступных устройств. Найденный прибор не заменяет объект проекта автоматически: пользователь подтверждает сопоставление.

## Передача

Перед любой реальной передачей выполняется предварительная проверка выбранного устройства. Конфигурации предназначаются конкретным устройствам и обрабатываются последовательно, а не отправляются одновременно во всё найденное оборудование.

## Почему так

Один рабочий процесс проще для пользователя, уменьшает количество дублирующихся экранов и позволяет подготовить проект полностью до появления физического оборудования.
