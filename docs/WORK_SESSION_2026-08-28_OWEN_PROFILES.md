# Рабочая запись: проверенные профили ОВЕН

## Что сделано

Проведена внешняя проверка официальных страниц ОВЕН для ПР100 и ПМ210. На основе подтверждённых сведений создан `VerifiedOwenProfiles.cs`.

Для ПР100 добавлены отдельные профили восьми документированных модификаций, а не один общий профиль семейства. В профилях отражаются различия по количеству и типу I/O и наличие/отсутствие RS-485.

Для ПМ210 добавлен отдельный профиль коммуникационного шлюза. Он не представлен как контроллер для загрузки пользовательской программы.

## Как была понята задача

Требование пользователя о «реальных конфигурациях» нельзя выполнять фиктивными данными. Программа должна хранить то, что действительно подтверждено документацией, и явно отделять известные возможности от ещё не реализованных.

## Почему выбран такой вариант

ПР100 выпускается в нескольких модификациях с разными наборами I/O. Поэтому семейный профиль с диапазонами I1…I12/Q1…Q8 недостаточно точен для выбора конкретного устройства. ПМ210 по назначению является сетевым шлюзом, поэтому его нельзя ошибочно считать целью программирования ПР100.

## Важное ограничение

Сделанный профиль не является подтверждением полного физического обмена с прибором. Наличие профиля означает документированное описание модели. Реальные read/write и program-transfer адаптеры будут считаться завершёнными только после реализации и тестирования соответствующих протоколов.
