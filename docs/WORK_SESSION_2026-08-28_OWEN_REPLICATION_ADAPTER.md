# Рабочая запись — Owen Replication Utility adapter

## Запрос пользователя
«дальше больше лучше».

## Что проверено
Перед реализацией заново проверена официальная документация ОВЕН. ПР100 программируется в Owen Logic; официальная документация также описывает «Мастер тиражирования» как способ создать исполняемый файл для загрузки программы без участия Owen Logic. Для Windows мастер принимает `/silent`, `/ip:` для Ethernet и `/portname:` для USB/COM, а параметры результата можно направлять в файлы вывода.

## Как понята задача
Neutrivox должен уметь доводить пользователя от проекта и симуляции до реальной передачи, но не должен незаконно заменять или обходить стороннее программное обеспечение/защиту производителя.

## Принятое решение
Добавлен `OwenReplicationUtilityAdapter`. Он не содержит чужой бинарный код и не пытается реконструировать закрытый формат прошивки. Он использует установленный пользователем официальный Owen Replication Utility и передаёт ему только документированные аргументы после выполнения собственных проверок Neutrivox.

## Почему выбран этот вариант
Официальная документация прямо предоставляет поддерживаемый механизм тиражирования. Это безопаснее и технически честнее, чем придумывать собственный формат прошивки или reverse engineering. При этом Neutrivox остаётся единым интерфейсом проекта: пользователь выбирает конкретный target, Neutrivox проверяет состояние и запускает официальный механизм передачи.

## Ограничения
- Адаптер активен только для профиля с `ReadWriteSupported`.
- Путь к официальной утилите должен быть задан пользователем.
- COM endpoint передаётся как `/portname:`; сетевой endpoint — как `/ip:`.
- Ошибка или отмена процесса не объявляется успешной записью.
- Neutrivox не распространяет бинарник Owen Replication Utility.
- Нельзя считать поддержку готовой только по наличию профиля: профиль и production adapter остаются разными уровнями.
