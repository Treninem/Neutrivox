# Структура встроенной инструкции Neutrivox

Инструкция является частью программы и повторяет структуру единого рабочего процесса. Пользователь не должен искать разные руководства для проектирования, моделирования и подключения оборудования.

## 1. Быстрый старт
- создание проекта;
- добавление оборудования;
- настройка I/O;
- создание логики;
- запуск симуляции.

## 2. Оборудование
Для каждого устройства: назначение, поддерживаемые функции, каналы, параметры связи и статус поддержки.

## 3. Логика и моделирование
Пошаговое объяснение переменных, сетей логики, инструкций, запуска симуляции и анализа результатов.

## 4. Подключение реального оборудования
Обнаружение доступных устройств, проверка модели, сопоставление с проектом и диагностика связи.

## 5. Загрузка конфигурации
Подробный мастер: проверка проекта → выбор конкретного прибора → проверка соответствия → подтверждение → передача → проверка результата → следующий прибор.

## 6. Ошибки и решения
Каждая диагностическая ошибка должна объяснять: что произошло, почему это важно и что сделать пользователю.

## Принцип языка
Каждая статья хранится с русским и английским текстом. Технические термины сопровождаются простым объяснением, когда это помогает пользователю.
