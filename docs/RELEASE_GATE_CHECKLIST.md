# Neutrivox — Release Gate Checklist

Этот документ является контрольным листом финального выпуска. Никакая строка со статусом `PASS` не считается подтверждённой без фактического результата проверки.

## 1. Сборка

- [ ] `dotnet restore Neutrivox.sln`
- [ ] `dotnet build Neutrivox.sln -c Release`
- [ ] Smoke project собирается в Release
- [ ] Smoke project запускается без ошибок
- [ ] Нет нерешённых warning/error, которые блокируют выпуск

## 2. Рабочий сценарий проекта

- [ ] Создание нового проекта
- [ ] Добавление нескольких устройств
- [ ] Настройка I/O
- [ ] Создание логической сети
- [ ] Проверка логики
- [ ] Симуляция без физического оборудования
- [ ] Сохранение `.neutrivox`
- [ ] Повторное открытие
- [ ] Recovery после изменения

## 3. Физическое подключение

- [ ] Перечень COM-портов определяется реально
- [ ] Discovery можно отменить
- [ ] Неоднозначный endpoint не называется моделью
- [ ] Пользователь явно подтверждает binding
- [ ] Binding сохраняется в проекте
- [ ] Исчезнувшее устройство не считается автоматически готовым к deployment

## 4. Deployment

- [ ] Preflight запускается до физической операции
- [ ] Safety gate блокирует неподтверждённую операцию
- [ ] Наличие профиля не считается наличием загрузчика
- [ ] Для target требуется конкретный verified adapter
- [ ] Несколько устройств проходят строго последовательно
- [ ] Ошибка шага видна в итоговом отчёте
- [ ] Отмена не выполняет следующие шаги
- [ ] После обновления/смены endpoint старый план не используется молча

## 5. Лицензирование

- [ ] Free остаётся работоспособной
- [ ] Платные планы отображаются в RUB
- [ ] RU/EN описание существует для пользовательских тарифов
- [ ] Owner Lifetime не попадает в публичный список продаж
- [ ] Неверный ключ отклоняется
- [ ] Истёкший ключ отклоняется
- [ ] Привязанный ключ не активируется на другом fingerprint
- [ ] Секретный ключ подписи отсутствует в клиентском репозитории

## 6. Политика и безопасность

- [ ] Нет обхода сторонних лицензий/DRM
- [ ] Программа действует только в рамках полномочий пользователя
- [ ] Физические изменения требуют явного подтверждения
- [ ] Неподтверждённые протоколы не заявляются как реальные
- [ ] Тестовые адаптеры отделены от production adapters

## 7. Документация

- [ ] Руководство RU
- [ ] Руководство EN
- [ ] Инструкция по созданию проекта
- [ ] Инструкция по симуляции
- [ ] Инструкция по подключению
- [ ] Инструкция по последовательной передаче
- [ ] Разъяснение ограничений конкретных моделей

## 8. Установщик

- [ ] Windows Release опубликован
- [ ] Чистая установка на системе без исходников
- [ ] Запуск после установки
- [ ] Обновление существующей версии
- [ ] Удаление
- [ ] Ярлык/иконка
- [ ] Версия продукта отображается корректно

## Финальное правило

Релиз можно обозначить как `READY` только после выполнения всех блокирующих пунктов и сохранения фактического результата проверки в отдельной записи журнала.
