# Правила реальных профилей оборудования

## Источник истины

Профиль конкретного оборудования считается документированным только после сверки с официальной документацией производителя или другим надёжным первичным источником.

## ПР100

Официальная документация ОВЕН показывает несколько модификаций ПР100 с различными типами и количеством входов/выходов. В зависимости от модификации есть или отсутствует RS-485. Для вариантов с RS-485 в документации указан Modbus-RTU/Modbus-ASCII и режим Master/Slave. Поэтому Neutrivox не должен показывать одинаковую конфигурацию I/O для всех ПР100.

## Важное ограничение

Наличие Modbus не означает, что через Modbus разрешена загрузка пользовательской программы Owen Logic. Профиль ПР100 поэтому пока не заявляет программную загрузку как поддержанную возможность. Для неё требуется отдельная проверка формата проекта, способа передачи и фактического поведения устройства.

## Распознавание

IP-адрес сам по себе не является достаточным доказательством модели. Для идентификации используются подтверждённые признаки устройства, а результат имеет статус и уровень уверенности. Неизвестное или неоднозначное устройство не должно автоматически привязываться к проекту.

## Следующий шаг

Для каждой реальной модели добавляются: точная модификация, I/O, доступные транспортные интерфейсы, поддерживаемые протоколы, ограничения чтения/записи и, отдельно, подтверждённый способ программирования/передачи конфигурации.
