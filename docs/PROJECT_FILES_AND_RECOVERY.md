# Сохранение, файлы и восстановление проекта

## Формат проекта

Рабочий проект Neutrivox использует расширение `.neutrivox`. Формат содержит данные единого `AutomationProject`: оборудование, связи, теги и логику. Состояние симуляции не считается заменой конфигурации проекта.

## Загрузка

Перед использованием загруженного проекта приложение должно проверять, что данные действительно могут быть прочитаны, а структура не содержит критических нарушений. Ошибка загрузки должна быть показана пользователю понятным сообщением и не должна уничтожать уже открытый проект.

## Восстановление

Recovery points предназначены для возврата к недавнему состоянию при сбое или ошибочном изменении. Они ограничены по количеству, чтобы не потреблять неограниченную память. Постоянное хранение точек восстановления будет подключено на уровне приложения после завершения формата файлов и интерфейса.

## Целостность

Проверяются базовые структурные проблемы: пустой идентификатор проекта, повторяющиеся идентификаторы устройств и связи с отсутствующими устройствами. Предупреждения не должны молча превращаться в ошибки, а критические проблемы не должны скрываться.

## Почему это отдельный блок

Надёжное сохранение необходимо до работы с реальными устройствами: проект должен можно безопасно сохранить, повторно открыть и проверить до подготовки передачи в оборудование.
