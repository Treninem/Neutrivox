# Рабочая запись — лицензирование и deployment UI

## Запрос
Пользователь попросил делать больше за один заход.

## Сделано
- Добавлен `LicensePresentationService` для RU/EN планов и цен в рублях.
- Добавлен `LicenseUiStateService` для единого состояния лицензии и доступности функций.
- Добавлен `DeploymentUiStateService` для состояния последовательной передачи и прогресса.
- `DeploymentReportService` расширен русским и английским выводом.
- Сверен текущий `MainWindow`: проект, оборудование, схема, логика, симуляция и подключение используют общий проект.

## Решение
Состояние лицензии и deployment не вычисляется независимо в каждом экране. Используются общие presentation/state-сервисы, чтобы не дублировать правила.

## Ограничение
Наличие платного плана не означает поддержку физической записи. Передача остаётся разрешённой только через safety gate и проверенный adapter.

## Дальше
Интегрировать сервисы в UI, затем провести compile/CI pass и исправить реальные ошибки. После стабильной сборки — production adapter только для подтверждённого способа программирования конкретной модели.
